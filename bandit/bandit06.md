## Process
After connected, the first thing i do is type
```bash
ls
```
It doesnt show anything. So we take a look of the hint.
- owned by user bandit7
- owned by group bandit6
- 33 bytes in size
  
So we can use command 'find' like this
```bash
find / -user bandit7 -group bandit6 -size 33c
```
It show a lot of folder/file but the permission denied. To anticipate it we use '2>/dev/null' that mean to discard all standard error (stderr) messages generated by a command. So i type
```bash
find / -user bandit7 -group bandit6 -size 33c 2>/dev/null
```
And at this point we know bandit7 password in /var/lib/dpkg/info/bandit7.password. Then i command
```bash
cat /var/lib/dpkg/info/bandit7.password
```
