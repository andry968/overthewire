## About OverTheWire

[OverTheWire](https://overthewire.org/wargames/) offers a series of wargames designed to teach and practice security concepts in a fun, hands-on way.

Topics covered across the wargames include Linux command line, file permissions, networking, cryptography, privilege escalation, binary exploitation, and more all from your terminal.

## What You'll Learn

Going through these writeups, you'll pick up skills in:

- Linux file system navigation and permissions
- SSH, port forwarding, and networking basics
- File encoding and decoding (Base64, hex, ROT13, etc.)
- Process inspection and environment variables
- Scripting and command chaining
- And more as levels progress

---

## Tips Before You Start

- Always try the level yourself before reading the writeup
- OverTheWire has an active community, the [Discord](https://discord.gg/overthewire) is helpful if you're stuck
- Each level builds on the previous one, don't skip ahead
- Document your own solutions as you go, it helps retention
